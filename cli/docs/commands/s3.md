# S3 对象取证

`doctor s3` 按 mc 的 `ls`、`stat`、`cat` 命令习惯浏览对象存储。Service 相当于连接别名，
连接来自 Plugin 已声明的 S3 DataSource。`doctor store` 保持健康、容量和负载总览。

## 使用

```bash
doctor s3 ls app --format summary
doctor s3 ls app/bucket/hibot/workspace-snapshots/ --format summary
doctor s3 ls app/bucket/hibot/ --recursive --max-items 2000
doctor s3 stat app/bucket/path/file.txt
doctor s3 cat app/bucket/path/file.txt --max-bytes 4096 --format summary
doctor s3 stat --service app s3://bucket/path/file.txt --version-id VERSION
doctor s3 ls app/bucket/ --data-source archive --continuation-token TOKEN
```

`ls Service` 列出账号可见的 buckets；`ls Service/bucket/prefix/` 使用 `/` delimiter，列出当前层
对象和子前缀。`--recursive` 去掉 delimiter，递归列出匹配对象。前缀按字面匹配，需要目录语义时
保留末尾 `/`；S3 中的目录是 key 前缀，不是独立目录对象。

`stat Service/bucket` 使用 HeadBucket；带 key 时使用 HeadObject。`cat` 读取精确 key 的有界
内容。不先列 bucket 或目录，因此已知对象的查询不要求 ListBuckets / ListObjects 权限。

指定 `--service` 后，路径为 `bucket/key` 或 `s3://bucket/key`；不指定路径时 `ls` 列 buckets。
省略 Service / DataSource 时，唯一候选自动选择；多个候选在终端选择，非交互环境要求参数明确。
Service 只提供连接身份，配置中的 bucket / prefix 作为来源信息记录，不隐式添加到用户路径。
对象 key 不做 URL 解码、斜线合并或 `..` 归一化；含空格、通配符的 key 应使用 shell 引号。

## 连接与生命周期

`datasource/s3.ts` 为 `store` 和 `s3` 共享配置解析与访问准备。Service 可以声明标准环境变量映射，
也可以贡献 `source` 工厂。实际访问复用 toolbox 的 `S3DataSource`、`S3Client` 与根 ClientManager，
不新增 S3 SDK、凭据配置文件或 mc 子进程。内部 Service endpoint 使用共享 Kubernetes 转发，保持
原始 Host、TLS 和 SigV4 身份；工厂贡献的 client 保留自身访问通道。

## 结果与限制

默认最多 1000 条 bucket / 对象 / 子前缀，单页最多 1000 条；`--max-items` 上限 100000。
`cat` 默认读取 64 KiB，`--max-bytes` 上限 16 MiB。`--timeout` 默认 15 秒，上限 300 秒，作用于
连接准备完成后的 S3 操作；连接准备沿用共享客户端超时。所有操作只读，不提供复制、删除或写入。

达到条数、字节或时间限制时标记 partial / failed，并保留已取得结果。分页游标用于下一次 `ls`，
必须保持相同连接、bucket、prefix 与递归选项；它不是对象存储的一致性快照。分页失败不能证明
目录为空。成功的空清单只证明当前查询范围没有匹配项，不能单凭它证明整个存储或历史快照不存在。
403 表示无法判断存在性；HEAD 的 404 也不能可靠区分 bucket、对象和版本缺失。

输出复用 Evidence 与根交付流程：默认 HTML + Bundle，也支持 JSON、Manifest 和终端 Summary。
`diagnosis.json` 的 `resultFile` 指向原始 JSON，保存结构化清单、元数据、截断状态和协议错误码；`cat` 的原始字节独立保存在
`content.bin`，Summary 预览可解码的 UTF-8 内容，二进制提示读取原始文件。
`--format summary` 不支持 `--output`。这里的 `cat` 是诊断读取，不是可直接通过管道复制文件的 mc 替代品。
连接密钥与 SDK 原始报错不进入结果；对象名称、元数据和内容仍是业务取证数据。
